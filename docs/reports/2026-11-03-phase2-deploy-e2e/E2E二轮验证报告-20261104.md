## 六、方法论纠偏（覆盖上一轮 HANDOFF §三 方法教训 1）

上一轮结论「不能靠改注册表 sessionId 复制调度员会话」**不成立**。真实原因两条：
1. F-1 使 `getNanjuRouterPrompt` 在 `assertACFamilyDiversity` 抛错 → 会话拿不到调度员提示词 → LLM 裸奔被 W19 拦（表现为「接管失败」）；
2. bridge `create_session` 未传 `workspace_id` → `workspace=null` → orchestrator 跳过 router prompt 注入，且
   PHASE_ADVANCE 消费条件（`workspaceSlug` 非空）不成立（标记输出 3 次零消费）。

正确姿势：`create_session` 必须带 `workspace_id=16171483-8f38-465e-8ff5-94a400b36562`，并同步注册表
`_nanju-projects.json` 与工程 `_project-info.json` 的 `sessionId`。修复后同一手法一次成功。
