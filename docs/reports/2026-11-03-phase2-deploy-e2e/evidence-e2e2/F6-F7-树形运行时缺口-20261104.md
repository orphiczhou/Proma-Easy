## F-6：树节点会话被未绑定写保护拒绝（已修复，v0.17.137）

### 现象

NEXT-02 建树成功后，A-worker（`727879b8`）写 `08_APP` 被路由门禁拒绝：

```
南大向导写保护：当前会话未绑定南大项目，不能直接写入项目目录。
本次 Bash 命令目标位于项目「个人记账工具」的 根目录内。…
```

日志：`[南大路由门禁] 拒绝工具 Bash`（2 次）。

### 根因

`checkUnboundSessionWriteGuard`（nanju-router-gate.ts）只豁免 `isDelegationChildSession`（带
`sourceDelegationId` 的协作委派子会话）。NEXT-02 的树节点会话由树桥直接
`createAgentSession` 创建，不是 delegation 子会话 → 命中「未绑定会话写保护」，
写类工具与 Bash 全部被拦 → 树形编码无法落盘，NEXT-02 运行时闭环断裂。

### 修复（最小授权面）

- 新增 `isTreeMemberSession(workspaceSlug, project, sessionId)`：读取
  `<workspace-files>/.context/trees/<project.treeId>/tree-state.json`，命中任一叶
  `session_id` 即视为该工程的树成员；读取失败 fail-closed（false）。
- 守卫命中项目后追加豁免：仅当命中工程 === 该会话所属树工程时放行；写其他工程目录仍拒绝。
- 单测 4 条：树 worker 写自身工程放行 / 自身工程 Bash 放行 / 写别的工程仍 deny / 非树会话仍 deny。
- 门禁：typecheck 全绿；`bun run test` 2841 pass / 0 fail。
- 部署：v0.17.137（备份 `app.asar.bak-pre-v0.17.137-20261104-0150`），重启后无 ERR_DLOPEN。

## F-7：树形流程缺少事件唤醒（未修，观测项）

### 现象

2026-11-04 02:24 之后，root 汇报「等待 B 审计结论」并结束本轮；A/B/C 全部空闲，
树内无新事件达 23 分钟。root 不会因 B 叶 `done`/`audit_append` 事件被自动唤醒——
树事件通道没有回流到会话 run 的唤醒机制（与 delegation 的
`wait_for_delegations` 不同，tree 侧无等待原语）。

### 影响

无人值守场景下，树形编码会在「审计完成但 root 未感知」处停滞；需要外部（用户/巡检）
发消息推动，或由 root 主动轮询（本轮的 nudge 即人工补位）。

### 证据

- 树状态：`A-worker done`、`B-worker done + gate pass`，而 root 任务仍 `in_progress` 且无 run。
- 手动 send_message 巡检后，root 立即恢复：读 B 会话 → 汇总 round-1 审计（101 AC：green 81 /
  yellow 16 / red 4）→ 向 A 下发修复轮 + `tree_log_communication` 留痕。

### 建议（未实施）

在 tree 事件写入点（`tree_event_append` / `tree_audit_gate` / `tree_milestone_set_result`）
向 root 会话注入系统续接消息（systemInitiated，同阶段推进续接通道），或提供
`tree_wait_for_events` 类等待原语。
