## 二、页面说明

### 1. 模式选择页

- **用户看到**：两个并排卡片——"快速做一个工具" / "做一个长期维护的项目"
- **用途**：用户首次启动应用时选择项目走向。
- **进入时机**：应用首次启动、所有项目已关闭时回到此页。
- **页面内区域**：
  - 1a. "快速做一个工具"入口卡片：大标题+副标题"适合试试想法、做个小工具、验证一个点子"+场景举例"比如：做个读书笔记、订餐统计、个人记账"+进入后说明"聊天在左，预览在右，直接说你的需求"
  - 1b. "做一个长期维护的项目"入口卡片：大标题+副标题"适合想持续更新、不断完善的项目"+场景举例"比如：开源工具、团队协作平台、长期维护的社区网站"+进入后说明"聊天在左，文档在中间，预览在右，有专业引导帮你打好基础"
  - 卡片hover高光效果
  - 无顶部导航栏（减少干扰，强制选择）
  - 原生窗口关闭按钮可用（退出应用）
- **可跳转到**：2-快消型工作区、3-长期迭代型工作区
- **入口来源**：关闭项目后返回；通过URL/快捷键绕过选择时强制回到此页
- **参照Demo**：TypeACardSelection

### 2. 快消型工作区

- **用户看到**：状态栏标签"快速做一个工具"，聊天界面在左，预览画面在右
- **用途**：用户通过聊天与向导Agent协作，快速完成需求沟通→原型确认→开发→测试→交付的全闭环。
- **进入时机**：在模式选择页点击"快速做一个工具"卡片后。
- **页面内区域**：
  - 2a 聊天区（左栏）：对话消息流（用户消息气泡+Agent回复+测试结果摘要卡片），卡片选项组（替代文本输入），底部输入区域（文本+截图上传 `[支持PRD §7.3截图标注反馈]`），顶部状态指示栏（当前阶段文案如"正在了解你的需求…""AI正在设计技术方案…"）
  - 2b 预览区（右栏）：HTML原型渲染区（sandboxed iframe），点选纠错交互层（点击元素→高亮→快速选项→修改）
  - 2c 时间轴面板：右侧滑出，版本列表+回滚确认弹窗。入口为工具栏"历史版本"按钮
  - 2d 状态通知层：全局底部Toast，5种通知类型（等待/成功/失败/回滚/超时），零术语+amber色，对应PRD §7.5全部5条文案
  - 2e 工具栏：顶部，"我的项目""历史版本""设置""升级为长期项目"四个入口
- **快消型特有约束**：
  - 无文档面板
  - 架构设计/工程规划阶段不弹出新面板，状态栏显示进度文案，预览区自动更新
  - PRD确认、架构设计、团队配置均为后台过程，用户不可见
  - 测试全部通过后，聊天区自动插入**测试结果摘要卡片**（参照US-U08：通俗描述+通过/失败统计+可展开详情）
- **可跳转到**：1-模式选择页（关闭项目）、4-我的项目页、5-设置页、3-长期迭代型工作区（升级项目时）
- **参照Demo**：TypeBSplitPane（聊天+预览分栏）、TypeCClickToFix（点选纠错）、TypeDTimeline（时间轴）、TypeEStatusNotifications（状态通知）、TypeFIframePreview（原型渲染）

### 3. 长期迭代型工作区

- **用户看到**：状态栏标签"做一个长期维护的项目"，聊天界面在左，文档在中间，预览在右
- **用途**：用户通过聊天与向导Agent深度协作，完成需求文档→架构设计→开发计划→编码→测试→版本交付→持续迭代的完整软件工程流程。
- **进入时机**：在模式选择页点击"做一个长期维护的项目"卡片后；或从快消型项目升级后。
- **页面内区域**：
  - 3a 聊天区（左栏）：同快消型聊天区（含测试结果摘要卡片+进度消息）。架构设计确认和开发计划确认以**内嵌消息卡片**形式出现在对话流中（用高亮边框+底色+底部操作按钮与普通消息区分，出现时自动滚动并闪烁提示）。角色切换时在对话流中插入系统分隔消息提示当前角色变化（如"接下来由架构设计师与你讨论技术方案"），用户可知角色切换但始终感觉在同一个对话中。每个卡片选项组包含"你帮我决定"选项。
  - 3b 文档面板（中栏）：需求沟通阶段完全隐藏。AI生成需求文档后通过聊天区内嵌消息提示用户查看，用户主动点击后展开。文档目录树（按01_PRD~07_VERSIONS层级展示），文档内容查看器（点击文档在面板内渲染），每个章节附带"确认/修改"入口。用户界面中统一使用"需求文档""开发计划"等通俗名称，禁止出现PRD/Sprint等技术缩写。
  - 3c 预览区（右栏）：同快消型预览区。首次进入时显示半透明引导提示"点击预览中的任意元素可以直接修改"。支持单击单个元素和框选多个元素批量操作。
  - 3f 时间轴面板：右侧滑出。项目尚无快照时面板显示"暂无历史版本"+引导说明。不提供手动创建快照入口（仅系统自动触发）。连续重复异常时变更安抚文案（不简单重复相同内容）。
  - 3g 状态通知层：严重通知（失败/超时）升级为聊天区顶部横幅或消息流插入，不自动消失；轻量通知（成功/回滚/等待）保持底部Toast。五类场景均用amber色+零术语。
  - 3h 工具栏：顶部，"我的项目""历史版本""设置"
- **长期迭代型特有约束**：
  - 三栏布局（聊天+文档+预览）
  - 架构设计师和工程经理跳到前台，通过**聊天区内嵌卡片**交互（不弹出独立覆盖面板，保持用户始终在聊天语境中）
  - 文档面板在需求文档确认后激活（需求沟通阶段完全隐藏 `[推断]`）
  - 测试结果在交付时以摘要卡片展示于聊天区（同快消型）
  - 会话中断后恢复：意外关闭/断网后重新打开，恢复到上次对话最后一个状态，向导Agent展示恢复引导
- **可跳转到**：1-模式选择页（关闭项目）、4-我的项目页、5-设置页
- **参照Demo**：TypeBSplitPane扩展为三栏、TypeDTimeline、TypeEStatusNotifications、TypeFIframePreview

### 4. 我的项目页

- **用途**：展示用户所有历史项目列表，支持查看、继续、删除项目。
- **进入时机**：从工作区工具栏"我的项目"入口进入；关闭当前项目后自动跳转至此。
- **页面内区域**：
  - 项目列表（卡片或表格，每个项目显示名称、模式图标、创建日期、最后活动时间）
  - 单项目操作菜单（打开继续、删除）
  - 删除确认弹窗（二次确认）
  - 返回工作区/新建项目入口
- **可跳转到**：1-模式选择页（新建）、2-快消型工作区（继续快消项目）、3-长期迭代型工作区（继续长期项目）

### 5. 设置页

- **用途**：用户管理个人偏好、查看数据使用说明、获取帮助。
- **进入时机**：从工作区工具栏"设置"入口进入。
- **页面内区域**：
  - 5a 数据与隐私子页：数据存储位置说明、隐私政策（通俗版）、删除所有数据按钮（二次确认）
  - 5b 关于/帮助子页：应用版本、使用指南（零术语）、反馈入口
- **可跳转到**：返回原工作区

### 6. 后台分析看板

- **用途**：研究者查看用户使用平台的关键指标——项目成功率、Token分布、认知摩擦指数——为论文和实验分析提供量化数据。
- **进入时机**：研究者从设置页的隐藏入口进入（不向零基础用户展示）。
- **页面内区域**：
  - 6a 效率看板：各项目类型MVP触达时间中位数、成功闭环率、放弃率（图表+筛选）
  - 6b 认知摩擦子页：用户意图修正频次分布、点选纠错使用率、平均撤销次数（分组对比）
  - 6c Token效率子页：需求/设计/编码/测试各阶段Token消耗占比（图表+分组对比）
  - 6d 文档合规子页：裁判Agent通过率时间趋势（折线图+异常标注）
  - 6e 范式挖掘子页：对话模式特征聚类分析、最佳指令范式摘要
  - 6f A/B实验管理子页：实验创建、分组配置、对比分析结果（含p值统计检验）
  - 数据导出功能（CSV格式，脱敏）
- **可跳转到**：返回设置页
- **入口可见性**：零基础用户不可见此入口，仅研究者账号可访问

## 三、全局UI元素

| 元素 | 出现位置 | 说明 |

## 四、两种工作区布局对比

| 布局特性 | 快消型工作区 | 长期迭代型工作区 |
|---------|------------|----------------|
| 分栏数 | 2栏（聊天+预览） | 3栏（聊天+文档+预览） |
| 文档面板 | 无 | 有（PRD确认后激活） |
| 架构设计师 | 隐于后台，状态栏显示进度 | 跳到前台，聊天区插入内嵌确认卡片 |
| 工程经理 | 隐于后台，状态栏显示进度 | 跳到前台，聊天区插入内嵌规划卡片 |
| 测试结果 | 聊天区插入摘要卡片 | 聊天区插入摘要卡片 |
| 快照触发 | 自动（关键节点） | 自动（关键节点） |
| 升级入口 | 工具栏"升级为长期项目" | — |
| 聊天区特殊消息类型 | 测试结果卡片 | 测试结果卡片 + 设计确认卡片 + 规划确认卡片 |
