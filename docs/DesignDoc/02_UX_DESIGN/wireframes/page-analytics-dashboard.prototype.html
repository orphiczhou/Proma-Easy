排名前 3 的最佳指令范式

基于高效用户对话模式提取
范式 #1 · 采纳率 91.5%
"先做一个包含 [A] [B] [C] 的基础版本"
结构明确的分步请求范式。用户在一句话中同时指定了"做什么"（基础版本）和"有什么"（功能清单A/B/C），Agent无需追问即可直接生成。平均节省 2.3 轮对话。
Token节省 34%成功率提升 22%推荐用于快消型
范式 #2 · 采纳率 85.2%
"把 [A] 改成 [B]，同时也调整一下 [C]"
带上下文的批量修改范式。用户在一个修改指令中同时表达了对元素A的变更和对元素B的关联调整，Agent可以一次性理解完整修改意图。平均节省 1.8 轮修正。
Token节省 28%修改准确率 94%推荐用于点选纠错
范式 #3 · 采纳率 78.6%
"这个效果不错，但在 [具体位置] 需要调整"
肯定+精准定位的反馈范式。用户先肯定了整体方向（降低Agent的决策不确定性），再精准定位需要修改的位置。Agent可以精确执行而非重新理解意图。
Token节省 22%单轮修正成功率 87%推荐用于长期迭代型
