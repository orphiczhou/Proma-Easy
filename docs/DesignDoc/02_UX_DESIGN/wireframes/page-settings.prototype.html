设置

你的数据存在哪里

你的项目数据保存在你的电脑上。所有对话记录、项目文件都存储在本地，不会自动上传到云端。

Windows
C:\Users\你的用户名\AppData\Local\Proma\
macOS
~/Library/Application Support/Proma/

隐私政策

通俗版

我们用最简单的话告诉你——你的数据怎么用、你有什么权利。

我们收集的内容

  • 对话记录：你和AI聊天的所有内容
  • 操作行为：你点击了什么、修改了什么、选择了什么选项
  • 使用统计：你用了哪些功能、用了多长时间

数据的用途

  • 改进产品：我们分析使用模式来让产品更好用
  • 学术研究：脱敏后的数据（去掉你的个人信息）用于研究

你的权利

  • 你可以在任何时候删除所有数据
  • 数据只保存在你的电脑上，不上传云端
  • 删除后数据不可恢复

删除所有数据

删除后，所有项目数据将被永久清除，包括对话记录、项目文件和历史版本。此操作不可撤销。

使用指南

以下是用最简单的话写的使用说明。

1

选择适合你的方式

打开应用后，你会看到两个选择——"快速做一个工具"和"做一个长期维护的项目"。选一个适合你的方式开始。前者适合试试想法、做个小工具；后者适合想持续更新、不断完善的项目。

2

用聊天描述你的需求

直接在聊天框里说出你想做什么，AI会像朋友聊天一样引导你理清思路。你只需要回答它的问题，不用操心任何技术细节。如果你拿不定主意，还可以选"你帮我决定"。

3

看预览、提修改

AI做出原型后，你可以在右侧看到它的效果。如果哪里不满意，直接点击页面上的元素，AI就会明白你想改哪里。你也可以直接说"把这个按钮换成蓝色的"。

4

大胆尝试，随时回退

系统会自动保存每个重要版本，就像游戏的自动存档。你随时可以翻看历史版本，回到之前的状态——所以放心大胆地提各种修改意见，不用怕搞砸。

5

完成交付

AI做完后，你会看到一份检查清单，告诉你测了什么、结果如何。全部通过后，你的工具就做好了。如果是长期项目，还可以继续提新需求进入下一个开发周期。
