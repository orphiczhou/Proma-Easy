## 子任务（2个SubAgent并行）

### A2.1 多 System Prompt 动态切换可行性

**核心问题**：Proma 能否支持一个会话中运行时切换 System Prompt？如果不能，最小改动方案是什么？

**调查项**：
1. 当前 System Prompt 的加载时机（会话创建时？每条消息时？）
2. System Prompt 的存储形式（代码常量？配置文件？外部文件？）
3. 切换 Prompt 的接口是否存在？（如 `agent.setSystemPrompt()` 或类似机制）
4. 如果不存在，改动量预估：新增路由中间件 → Prompt 文件管理 → 切换触发逻辑

**输出**：可行性结论（✅/⚠️/❌）+ 方案建议 + 改动量

### A2.2 多模型并发调用可行性

**核心问题**：Proma 的 API 调用层能否在同一个会话中同时向不同模型发请求？

**调查项**：
1. 当前模型调用是怎么实现的？（查 API 调用的代码路径）
2. 一个会话对象是否绑定单一模型？
3. 能否创建多个 "子会话" 或 "虚拟 Agent" 各自调用不同模型？
4. Proma Cloud API 的并发调用限制？

**输出**：可行性结论（✅/⚠️/❌）+ 方案建议 + 改动量
