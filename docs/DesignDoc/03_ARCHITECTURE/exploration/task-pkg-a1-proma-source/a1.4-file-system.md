## 工作区目录结构

```
~/.proma/
  agent-workspaces.json          # 工作区索引
  agent-workspaces/
    {slug}/                      # 每个工作区
      config.json                #   工作区配置
      mcp.json                   #   MCP服务器配置
      skills/                    #   活跃Skills
      skills-inactive/           #   禁用Skills
      workspace-files/           #   跨会话共享文件 ★ 最佳挂载点
        .context/                #     工作区级长期文档
      {sessionId}/               #   每个会话的独立工作目录(Agent cwd)
        .claude/settings.json    #     SDK设置
        .context/                #     会话级临时文档(todo/plan/)
```

**证据**：上述目录结构由 `config-paths.ts` 中的路径函数定义，详见路径管理小节每个函数的行号引用。

## 权限控制

三种权限模式（运行时动态切换）：
- **bypassPermissions**: 全自动放行
- **auto**: 只读工具自动放行，写操作询问用户
- **plan**: 仅允许只读+`.md`写入+只读Bash

安全工具（免询问）：Read/Glob/Grep/WebSearch/WebFetch/TodoRead/TodoWrite/TaskOutput
安全Bash命令（免询问）：git status/log/diff、ls、head、tail等

**证据**：

权限模式运行时切换定义于 `agent-orchestrator.ts` L2179-2191 `updateSessionPermissionMode()`，通过 `sessionPermissionModes` Map（L518）和 SDK 的 `setPermissionMode()`（`claude-agent-adapter.ts` L907-913）实现。

SAFE_TOOLS 定义于 `packages/shared/src/constants/permission-rules.ts` L9-18：
```typescript
export const SAFE_TOOLS: readonly string[] = [
  'Read', 'Glob', 'Grep', 'WebSearch', 'WebFetch',
  'TodoRead', 'TodoWrite', 'TaskOutput',
]
```

安全 Bash 命令模式定义于同一文件 L22-48（SAFE_BASH_PATTERNS），包含 `git status/log/diff/show/branch/remote/tag`、`ls`、`head`、`tail`、`grep`、`rg`、`which`、`pwd`、`env`、`whoami`、`uname`、`tree`、`wc`、`file`、`stat`、`du`、`df` 等。

危险命令列表定义于 L51-63（DANGEROUS_COMMANDS），包含 `rm`, `sudo`, `chmod`, `mv`, `dd`, `kill`, `git push`, `git reset`, `npm publish`, `curl`, `wget`, `ssh` 等。

权限模式实现于 `agent-permission-service.ts`：
- `AgentPermissionService` 类定义：L107-404
- `createCanUseTool()` 回调：L120-163（auto 模式本地 classifier，只读操作自动放行 L142-145）
- `isReadOnlyTool()` 分类判断：L221-232

## 项目脚手架机制

**Proma没有通用项目模板或脚手架机制。** 最接近的是：

1. **`seedDefaultSkills()`**: 首次启动同步内置Skills到用户目录
   **证据**：`config-paths.ts` L467-516，由 `index.ts` L426 在 bootstrap 时调用。
   同步策略：缺失直接复制，已存在则比较 SKILL.md 中 version 字段（L496-506），bundled 更新时才覆盖。

2. **`createAgentSession()`**: 创建会话时初始化 `.claude/settings.json` 和 `.context/` 目录
   **证据**：`agent-session-manager.ts` L99-157：
   ```
   L123-126：获取 sessionDir
   L129-147：初始化 .claude/settings.json（设置 plansDirectory → '.context'、skipWebFetchPreflight → true）
   L150-151：初始化 .context/ 目录
   ```
