## 依赖链

```
shared (无依赖) → core (依赖shared) → ui (依赖core+React) → electron (依赖全部三个包)
```

**证据**：
- `packages/core/package.json` 中声明 `@proma/shared` 依赖
- `packages/ui/package.json` 中声明 `@proma/core` 和 React 依赖
- `apps/electron/package.json` 中声明所有三个包的依赖
- `apps/electron/src/main/lib/agent-orchestrator.ts` L38-39 同时 import 自 `@proma/core` 和 `@proma/shared`

## 关键发现

1. **所有核心Agent逻辑集中在 `apps/electron/src/main/lib/`（86个模块文件）、三个packages相对薄**
   **证据**：`apps/electron/src/main/lib/` 目录通过 `ls | wc -l` 统计为86个文件（不含嵌套子目录），而 `packages/shared/src/` 约30+文件、`packages/core/src/` 约15+文件、`packages/ui/src/` 约10个文件。

2. **Skill通过SDK Plugin系统加载，12个内置Skill随应用分发**
   **证据**：`agent-orchestrator.ts` L1544 `plugins: [{ type: 'local' as const, path: getAgentWorkspacePath(workspaceSlug) }]`；`default-skills/` 目录通过 `ls` 统计有12个Skill目录（见上方目录树）。SDK自动发现 `skills/` 目录下的 SKILL.md。

3. **前端使用shadcn/ui组件体系，基于Tailwind CSS变量实现暗色模式**
   **证据**：`apps/electron/src/renderer/components/ui/` 目录包含 `button.tsx`、`dialog.tsx`、`dropdown-menu.tsx` 等 shadcn/ui 组件；`apps/electron/src/renderer/styles/` 包含全局CSS和暗色模式支持。

4. **渲染进程通过249个 IPC handlers 与主进程通信，contextIsolation 严格隔离**
   **证据**：`apps/electron/src/main/ipc.ts` 中 `grep -c "ipcMain.handle("` 统计为249个handler；`apps/electron/src/main/index.ts` L292-293 `contextIsolation: true, nodeIntegration: false`；`preload/index.ts` L2306 `contextBridge.exposeInMainWorld('electronAPI', electronAPI)` 严格通过安全桥接暴露API。
