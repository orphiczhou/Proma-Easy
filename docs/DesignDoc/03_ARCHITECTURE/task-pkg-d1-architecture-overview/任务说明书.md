## 三、产出章节

按以下结构撰写，每节附具体内容要求：

### 1. 技术选型

逐项列出并附**选择理由 + 否决方案**：
- 桌面壳：Electron（Proma自带）
- UI框架：React+TypeScript+Vite+Tailwind+Jotai+Radix UI（全部继承Proma）
- Agent通信：文件系统 + 直接函数调用（不用消息队列）
- 存储：JSONL/SQLite（零依赖原则）
- 沙箱：L0文件系统隔离 + L1子进程限制
- 模型调度：Proma现有API调用机制扩展

### 2. 模块划分

每个模块一句话职责 + 输入/输出边界：

| 模块 | 职责 | 关键实现 |
|------|------|---------|
| 前端UI层 | 6页面渲染、对话交互、原型预览 | 复用Proma Tab体系 |
| 对话路由层 | 按阶段加载角色System Prompt | Session Restart + Context Backfill |
| 向导Agent引擎 | 需求分析、UX生成、架构设计、工程规划 | 串行角色切换 |
| 编程Agent引擎 | 代码生成、自修复、GWT执行 | 调用GLM 5.1 |
| 裁判引擎 | 硬约束检查 + 软约束AI评估 | 文件校验 + LLM评估 |
| 快照管理器 | 自动快照、线性回滚 | fs.linkSync硬链接 |
| 埋点采集层 | 13事件全量采集 | JSONL追加写入 |
| 项目文档体系 | 7目录标准化 | workspace-files/挂载 |

- Session Restart + Context Backfill实现步骤
