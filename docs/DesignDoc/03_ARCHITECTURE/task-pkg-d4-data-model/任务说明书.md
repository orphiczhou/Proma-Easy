## 三、产出内容

### 必须覆盖的5个实体

#### 实体1：项目元数据（Project）
- 字段：projectId、name、mode(快消/长期)、template(Web全栈/CLI/...)、status(进行中/已完成/已放弃)、createdAt、updatedAt、currentStage(需求/原型/架构/编码/测试/交付)
- 关系：1→N 快照、1→1 会话上下文

#### 实体2：快照（Snapshot）
- 字段：snapshotId、projectId(外键)、timestamp、description(自然语言，如"确认原型后")、triggerType(初版生成/用户确认修改/模式转换/异常回滚前)、filePath(快照存储路径)
- 约束：快照为线性列表，不支持分支结构（不存储parentSnapshotId）

#### 实体3：埋点事件（TelemetryEvent）
- 字段：eventId、sessionId、projectId(可空)、eventType(枚举13种)、timestamp、payload(JSON，随事件类型变化)、userId(脱敏后)
- 13种eventType枚举值，对应PRD §12.4清单
- 约束：payload不包含用户真实个人信息

#### 实体4：Agent会话上下文（SessionContext）
- 字段：projectId、currentStage、currentRole(当前激活角色)、conversationSummary(对话摘要，≤2000字)、confirmedDecisions(已确认决策列表)、lastCheckpointId(最后快照ID)
- 用途：支持Session Restart + Context Backfill

#### 实体5：文档目录元数据（DocumentMeta）
- 字段：projectId、docPath(如01_PRD/prd.md)、docType(PRD/UX/ARCH/API/PLAN/TEST/VERSION)、version、status(草稿/待审/已确认)、lastModified
- 用途：裁判Agent硬约束检查时快速定位文档清单

### 数据模型规范

每实体必须包含：
- 字段名、类型(string/number/boolean/enum/timestamp/JSON)、是否必填、默认值、说明
- 主键和外键关系
- JSON示例（每个实体至少1条示例记录）

### 实体关系图

Mermaid ER图，展示5个实体的关系和基数(1:1 / 1:N)。
